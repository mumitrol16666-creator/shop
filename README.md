# Maestro Music Store

Публичная витрина музыкального магазина Maestro с каталогом, вариантами товаров,
корзиной-заявкой, Kaspi/WhatsApp и закрытой панелью закупщика.

## Возможности

- публичный каталог без внутренних закупочных данных;
- карточки товаров, варианты, остатки и подбор инструмента;
- корзина-заявка с передачей заказа в WhatsApp;
- закрытая панель `/admin/pricing` для склада и ценообразования;
- закрытая аналитика `/admin/analytics`;
- управление курсами и материалами Академии;
- постоянное хранение в D1 на Sites и в `.runtime-data` на VPS.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run build
node --test tests/*.test.mjs
```

`npm run build` одновременно пересобирает статический клиент для VPS и vinext-
версию для Sites. Сгенерированные `public/bundle.js` и `public/bundle.css` входят
в коммит, потому что VPS отдаёт их напрямую.

## Данные

- Исходные данные для первого запуска: `data/products.json`, `data/courses.json`.
- Рабочие данные VPS: `.runtime-data/` — не удаляются при обновлении кода.
- Sites: D1, схема в `db/schema.ts`, миграции в `drizzle/`.
- Загруженные на VPS изображения: `.runtime-data/uploads/`.

Запись JSON на VPS выполняется атомарно с резервной копией предыдущего файла.

## Безопасность админки

Пароль проверяется только на сервере. Браузер получает защищённую HttpOnly-сессию
на 12 часов. Публичный `/api/products` не возвращает себестоимость, закупочные
цены, данные поставщика или черновики.

Для смены пароля задайте на сервере:

- `ADMIN_PASSWORD_SALT`;
- `ADMIN_PASSWORD_HASH` — hex-результат `scrypt` длиной 64 байта;
- `ADMIN_SESSION_SECRET` — длинная случайная строка для постоянных сессий между
  перезапусками.

Без переменных используется встроенный аварийный хеш, но открытого пароля в
исходниках и клиентском файле нет.

## Публикация

GitHub Actions проверяет полную сборку и тесты на Node.js 22. На VPS скрипт
`scripts/deploy-vps.sh` по расписанию забирает подтверждённый `main`, сохраняет
рабочие данные, пересобирает клиент и перезапускает PM2. Проект также поддерживает
публикацию через Sites согласно `.openai/hosting.json`.
